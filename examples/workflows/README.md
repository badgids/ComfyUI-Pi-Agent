These examples use only nodes from this package. Load them after installing the custom node.

1. `01_status_and_models.json` — check plugin/Pi status and inventory ComfyUI models.
2. `02_project_plan.json` — create a production plan and show the JSON.
3. `03_tutorial_controller_builder.json` — compile workflow paths into a ComfyUI-native tutorial.

Edit file paths and output directories before queueing.
