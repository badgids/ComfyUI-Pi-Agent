# Code of conduct

Be respectful, specific, and constructive.

- Discuss code and behavior, not personal traits.
- Welcome new users and explain technical issues plainly.
- Do not shame people for language level, age, disability, experience, hardware, or choice of tools.
- Report security issues privately.
- Do not publish private data, credentials, personal paths, or private project files.
- Harassment, threats, discrimination, and deliberate disruption are not accepted.

Project maintainers may remove content or participation that violates these rules.
