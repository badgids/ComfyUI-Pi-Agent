## Purpose

Plan Krea 2 Edit workflows with grounded and latent reference conditioning.

## Procedure

1. Require the correct edit LoRA and edit adapter nodes.
2. Assign explicit roles to one or two reference images.
3. Validate reference geometry and output latent connections.
4. Treat GGUF LoRA application as experimental until validated.

## Required behavior

- Use plain, explicit language.
- Inspect live ComfyUI capabilities whenever possible.
- Do not hardcode personal paths.
- Do not download models or dependencies during plugin import.
- Preserve originals before edits or repairs.
- Clearly separate validated behavior from experimental behavior.
