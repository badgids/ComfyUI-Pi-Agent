These are original GPL-3.0-licensed operating guides for Pi. They describe how to reason about ComfyUI workflows, models, references, production projects, NLE handoff, tutorials, and supported third-party node packs.

They are **not** copied into a user's global Pi directory at startup. ComfyUI-Pi selects only a small number of relevant procedures for the current task. Full integration procedures are loaded only when a deep/tutorial request needs them.

## How to navigate this section

Use this page as the parent index. Every individual `SKILL.md` below links back here, back to the main documentation hub, and sideways to the previous and next skill.
