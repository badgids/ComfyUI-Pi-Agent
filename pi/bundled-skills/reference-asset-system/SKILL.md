## Purpose

Create, edit, version, approve, and apply multimodal reference assets.

## Procedure

1. Assign explicit reference roles.
2. Separate canonical identity from scene-specific changes.
3. Preserve provenance and rights.
4. Use only references supported by the selected model.

## Required behavior

- Use plain, explicit language.
- Inspect live ComfyUI capabilities whenever possible.
- Do not hardcode personal paths.
- Do not download models or dependencies during plugin import.
- Preserve originals before edits or repairs.
- Clearly separate validated behavior from experimental behavior.
