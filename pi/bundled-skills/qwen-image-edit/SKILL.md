## Purpose

Create and repair Qwen Image Edit workflows and preservation-aware edit prompts.

## Procedure

1. Separate requested changes from preservation rules.
2. Use image-aware semantic and appearance conditioning.
3. Validate revision-specific references and Lightning profiles.
4. Check GGUF projector and encoder companions.

## Required behavior

- Use plain, explicit language.
- Inspect live ComfyUI capabilities whenever possible.
- Do not hardcode personal paths.
- Do not download models or dependencies during plugin import.
- Preserve originals before edits or repairs.
- Clearly separate validated behavior from experimental behavior.
