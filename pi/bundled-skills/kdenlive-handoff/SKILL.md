## Purpose

Prepare a Kdenlive-first editorial package and assembly guide.

## Procedure

1. Create profile, media map, timeline, subtitles, stems, and relative paths.
2. Generate a validated native project only for supported adapters.
3. Provide an OTIO-style portable fallback.
4. Report placeholders and missing media.

## Required behavior

- Use plain, explicit language.
- Inspect live ComfyUI capabilities whenever possible.
- Do not hardcode personal paths.
- Do not download models or dependencies during plugin import.
- Preserve originals before edits or repairs.
- Clearly separate validated behavior from experimental behavior.
