## Purpose

Compile one or more workflows into a complete ComfyUI-native tutorial.

## Procedure

1. Preserve original workflows.
2. Create annotated tutorial copies, controller workflow, and overview workflow.
3. Generate Markdown and DOCX documentation.
4. Do not create a separate or private WebUI.

## Required behavior

- Use plain, explicit language.
- Inspect live ComfyUI capabilities whenever possible.
- Do not hardcode personal paths.
- Do not download models or dependencies during plugin import.
- Preserve originals before edits or repairs.
- Clearly separate validated behavior from experimental behavior.
