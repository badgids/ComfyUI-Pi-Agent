## Planned after 0.1.1

- Live active-canvas capture and workflow injection through official frontend APIs.
- Versioned model and adapter registries with hashes.
- Typed Pi extension tools for graph mutation and execution.
- Incremental dependency compiler with checkpoint resume.
- Full production bibles and adaptation maps driven by Pi sessions.
- Validated model-specific workflow builders for supported image, edit, video, speech, music, and audio families.
- Kdenlive versioned adapters and richer OTIO export.
- Tutorial update/diff nodes and expected-output technical validation.
- More complete ComfyUI V3 node implementation after the stable API is appropriate for broad release.
