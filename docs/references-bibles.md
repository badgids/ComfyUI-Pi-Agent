These assets use separate top-level project directories. Mood boards belong in `04_MOOD_BOARDS/`, reference sheets in `05_REFERENCE_SHEETS/`, storyboards in `06_STORYBOARDS/`, and structured bibles in `03_PRODUCTION_BIBLES/`. Approved and draft/rejected material are separated so an old reference is not selected accidentally.

## Reference assets

A reference asset records type, title, files, roles, descriptions, preservation rules, model hints, provenance, and rights.

## Character references

Separate canonical identity from wardrobe, dirt, injury, age variation, expression, and lighting. Retain individual panels as well as combined sheets.

## Voice references

Keep raw recordings separate from cleaned clips and model-specific embeddings.

## Mood boards

Assign each image a role such as color, lighting, material, architecture, wardrobe, camera, or atmosphere.

## Storyboards

A storyboard shot should store scene, shot ID, action, shot size, angle, movement, duration, dialogue, sound, references, and continuity.

## Bibles

Bibles are structured project memory. The compiler creates empty starter bibles so later tools can add approved entries without mixing unrelated information.
