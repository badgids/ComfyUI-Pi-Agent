This page is the map for the entire ComfyUI-Pi documentation set. You should never need to browse the repository tree looking for a guide.

## How to move around

Every documentation page has a navigation bar near the top and bottom:

- **Project README** returns to the main GitHub page.
- **Documentation home** returns here.
- **Previous** and **Next** let you move sideways through the guides in a sensible reading order.
- **Related** links jump to nearby subjects when useful.
- Specialized indexes, such as the [Bundled Pi skills index](../pi/bundled-skills/README.md), let you drill down into a group and climb back up again.
