## Fountain

Fountain is plain text with screenplay semantics. The parser keeps title-page fields, scene headings, action, character cues, dialogue, parentheticals, transitions, sections, synopses, notes, and page breaks.

## Starter screenplay

`Pi Fountain Screenplay` creates a valid starting document. It does not claim that a simple automatic conversion is a finished adaptation.

## Breakdown

The screenplay breakdown creates scene identifiers, locations, time of day, characters, summaries, and production placeholders.

## Shot list

The first-release shot planner creates editorially useful starter coverage. A director should edit it for the actual dramatic purpose, lens language, blocking, and budget.

## Book-to-screenplay direction

The architecture is ready for a Pi skill to create an adaptation map, treatment, beat sheet, scene list, and Fountain script while preserving source traceability.
